# JSON Tools

Free browser-based JSON utilities. Format, validate, minify, convert, compare, repair, query, and escape JSON locally.

**Site:** https://jsontools.cloud  
**License:** MIT

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL=https://jsontools.cloud` in `.env.local` for canonical URLs, sitemap, and robots.
