# Image Tools

Browser-based image utilities. Compress, resize, convert, crop, and remove common metadata locally.

**Site:** https://imageconverter.cloud  
**License:** MIT

## Limits

- Max 5 images per operation
- Under 5 MB each
- JPG, JPEG, PNG, WebP only

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL=https://imageconverter.cloud` in `.env.local` for canonical URLs, sitemap, and robots.
